# Assets

Every asset used in the game is recorded here with its source and license.

| Asset | Source | License |
| --- | --- | --- |
| Sprites (three class characters, the Wayfinder NPC, seven weapon looks, twelve creatures, three bosses) | Authored as text grids in `src/art/sprites.ts`, shaded by `src/art/shade.ts` | Original, no restrictions |
| Ground tiles and parallax backdrops for each stage | Painted in code by `src/art/tiles.ts` and `src/art/stageArt.ts` | Original, no restrictions |
| Projectiles, reticle, checkpoints, pickup, loot crates, shadow | Painted in code by `src/art/effects.ts` | Original, no restrictions |
| Sound effects and music | Synthesized at runtime from recipes and note patterns in `src/audio/synth.ts` and `src/audio/tracks.ts` | Original, no restrictions |
| Favicon | Drawn in code in `src/main.ts` | Original, no restrictions |
| Fallback creature shapes | Generated in code by `src/scenes/BootScene.ts` | Original, no restrictions |
| `public/assets/tilesets/tiles.png` (collision tile, not shown) | Generated by a one-off script | Original, no restrictions |
| `public/assets/levels/*.json` (stage maps) | Generated by `tools/gen-levels.mjs` | Original, no restrictions |

No third-party assets yet.
